# Self-hosted brand fonts (MYSHPTHEME1015)

Variable woff2 files, `latin` + `latin-ext` subsets (Hungarian ő/ű), taken from the
`@fontsource-variable/inter` and `@fontsource-variable/manrope` packages, version 5.3.0.

- Inter: SIL Open Font License 1.1
- Manrope: SIL Open Font License 1.1

License text: https://openfontlicense.org/open-font-license-official-text/

Files live in `web/fonts/`, served by `src/web/routes/static.ts` under `/fonts/` (lowercase `*.woff2` names only).
